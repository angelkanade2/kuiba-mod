# 魁拔 0.1.8 → Minecraft 1.20.1 Forge 移植

基于电脑快照 `kuiba-current-0.1.8-source.zip`（sha256 `2aea751652e9f900604e478f6fce7f5c068f4e56e72f282312d3a568dca34712`，176 个文件）。1.21.1 NeoForge 主线没有改，移植在独立分支上。

## 运行要求

- Minecraft **1.20.1**
- Forge **47.4.28** 或更新的 47.x（`mods.toml` 要求 `[47,)`，且仍是 1.20.1）
- **Java 17**（客户端和服务端都是）。编译机可以是 Java 21，Gradle 会自己拉 JDK 17
- 客户端和服务端都要装同一个 jar：`kuiba-0.1.8-forge-1.20.1.jar`
- 模组版本字符串：`0.1.8-forge-1.20.1`

## 安装

1. 装 Forge 1.20.1 47.4.28+。
2. 把 jar 放进 `.minecraft/mods`（服务端是 `mods`）。
3. 语言选简体中文。
4. 创造物品栏有「魁拔」。

源码：解压 `kuiba-0.1.8-forge-1.20.1-source.zip`，用 IDEA 打开含 `gradlew` 的目录，JDK 17，然后 `./gradlew build`。可安装包是 `build/libs/kuiba-0.1.8-forge-1.20.1.jar`（`reobfJar` 重混淆之后的那个）。

## 建议手测（这次环境没有进游戏点过界面）

按键和 1.21.1 快照相同：

| 键 | 作用 |
| --- | --- |
| R | 脉术修炼 |
| G | 开脉门（消耗饥饿，补满脉力） |
| V / B / N | 三个技能槽 |
| Z | 施放技能圆盘当前连招 |
| X | 固定连招 |
| 左 Alt（按住） | 技能圆盘 |
| J | 连招编辑 |

建议顺序：

1. 创造拿冲脉丹，右键冲脉。潜行右键取消。成功后应自动开一次脉，并听到 `open_mai_gate_xN`（N = 当前门数，1 到 12 各一条）。
2. `/kuiba gate 0` 到 `/kuiba gate 12` 看 HUD 脉值和门点。需要权限 2。
3. 主手拿纹耀，`/kuiba wenyao equip`，`/kuiba wenyao clear`。门数不够时纹耀不加属性。
4. 右键裂脉刃、凝脉枪，确认武器技。枪的攻击距离比刃多 0.8 格（Forge 的 `entity_reach`）。
5. 穿齐脉织甲：两件减慢脉力流失，四件命中回脉。刃命中也回一点脉。
6. 用五种特殊刷怪蛋。僵尸/骷髅 1–4 门掉脉碎片，猪灵系 1–6 门掉脉晶，末影人蛋 6–12 门掉脉核。自然生成：末影人只在末地开脉。
7. 开一台专用服务器，客户端连上去。开脉、技能、连招、死亡后的门阶都应以服务器为准。死亡保留门阶/已解锁/已装备（配置默认开），脉力按原版代码归零，不是注释里写的 30%。
8. 两名玩家互相靠近，应能看到对方身上的脉环。特殊怪大约每 30 秒播一次开脉动画和对应音效，伤害加成一直在。

## 和 1.21.1 快照的差别

玩法 id、物品、音效文件、配方材料、门阶表没有改。为了能在 1.20.1 上跑，这些地方换了实现：

- 数据组件改成物品类型 + 可选 NBT（`kuiba_wenyao_tier`、`kuiba_weapon_art`）。创造栏拿出来的纹耀和武器仍带原来的阶和武器技。
- NeoForge Attachment 改成 Forge Capability。玩家死亡时先整份复制，再按原逻辑裁剪。
- 网络包改成 `SimpleChannel`。客户端表现（同步、开脉特效）不从公共类直接引用 `net.minecraft.client`，专用服务器可以加载。
- 资源包 `pack_format` 15。配方 `result` 用 `item` 不是 `id`。进度在 `data/kuiba/advancements/`。
- 盔甲贴图从 1.21 的 `textures/entity/equipment/...` 拷到 1.20.1 的 `textures/models/armor/mai_weave_layer_1.png` 和 `_layer_2.png`。图本身就是 64×32。
- 1.21 界面的高斯模糊没有对应 API，修炼/连招界面改成半透明暗底。技能圆盘仍然不加这层底。
- 特殊怪身上的脉环不再读取 1.21 的通用 scale 属性（1.20.1 没有）。幼年怪仍按一半缩放。
- 伤害加成挂在 `LivingHurtEvent`（护甲结算前），对应原来的 `LivingDamageEvent.Pre`。真正扣血后才记“受击/造成伤害”。
- 属性修饰符用 UUID，数值和加减法与门阶表一致。
- `weapon_art/README.txt` 挪到 `docs/`，避免数据包把非 json 文件当成错误。

## 源码里注释和代码不一致的地方（移植没有改语义）

`MaiAttachments` / 配置注释写死亡后脉力变成上限的 30%。`MaiGameEvents` 里实际是 `setCurrent(0)`。1.20.1 版跟代码走，死亡后当前脉力为 0，门阶是否保留仍看 `keepGateOnDeath`。
